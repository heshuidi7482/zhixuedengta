关于《智学灯塔》

作品定位

《智学灯塔》是一款面向小学教师的AI个性化教学平台，围绕"AI备课—学情诊断—智能出题—课堂助教—本土课程资源"构建完整教学闭环。作品以"灯塔"为意象，寓意AI如灯塔般照亮因材施教之路，融合湛江红树林之城的地域特色。

AI技术与工具
  • 前端开发：原生 HTML / CSS / JavaScript（零外部依赖，双击即用）
  • 诊断算法：自研「知识点掌握度+遗忘曲线修正」模型，生成个性化学习路径
  • 智能体：本地知识库+规则引擎驱动的多场景教学智能体（预留大模型API接口）
  • 内容生成：AI生成教案/题目/情境题；配套AI生成图像、数字人解说视频（见演示视频）
技术亮点
  • 前端应用开发 + 本地持久化（localStorage）+ 数据导入导出
  • 自研学情诊断算法：多知识点加权掌握度模型 + 遗忘曲线修正 + 分层建议生成
  • AI能力融合：文本生成、语音识别接口预留、图像生成配套、知识图谱可视化
  • 湛江特色情境题库与跨学科课程包
